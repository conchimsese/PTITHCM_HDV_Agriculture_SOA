# Kiểm tra khung thư mục hiện tại

Bản hiện tại bỏ giao diện demo, form nháp, route theo role và browser test dành riêng cho demo. Web và mobile chỉ còn entry point tối thiểu; các feature có folder trống để nhóm code.

Các lệnh cần chạy: npm run check (typecheck, lint, 19 test API/contract, build web), npm run format:check, npm run export:android. Không còn test UI demo hoặc chức năng frontend hoàn chỉnh.

Chưa nối backend thật, chưa chạy ứng dụng nghiệp vụ trên thiết bị, chưa tạo APK. Các kết quả kiểm UI ở lịch sử commit trước không áp dụng cho bản khung trống này.
